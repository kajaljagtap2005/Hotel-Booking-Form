# Hotel-Booking-Form
Hotel Booking Form website built using HTML, CSS, and JavaScript for easy room reservation at  Resort.

* Fully functional and responsive hotel booking form with all required fields (check-in/out dates, room type, guest count, special requests).
* Implemented date validation ensuring checkout is after check-in and no past dates allowed.
* Added required field validation with error alerts for missing info.
* Dynamic features like real-time price calculation and min date update on check-in change.
* Attractive UI with animations, gradients, and mobile-friendly design.
* Form submission with success modal and data sent to your email via Web3Forms.
* Project Deploy Successfully
